# Custom Linked List Workout Tracker (Java)

A console-based gym workout tracker built from scratch in Java using a custom Singly Linked List data structure.

### Features
- **Custom Singly Linked List:** Implements insertion, deletion, and node traversal without relying on built-in Java Collections.
- **Dynamic 1RM Estimation:** Computes estimated 1-Rep Max using the Epley formula: `Weight * (1 + Reps / 30)`.
- **Total Volume Tracking:** Calculates cumulative tonnage per movement.
- **In-Memory CRUD:** Supports adding, editing weight/reps, deleting exercises, and displaying current session metrics.
